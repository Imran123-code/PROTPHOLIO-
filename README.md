## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/Imran123-code/PORTFOLIO-.git

# Navigate into project directory
cd PORTFOLIO-

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

---

## 🌐 Deploy to Vercel in 1 Click

1. Push your repository to GitHub: `https://github.com/Imran123-code/PORTFOLIO-`
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import this repository and click **Deploy**. Vercel will automatically detect Vite and publish your site!
